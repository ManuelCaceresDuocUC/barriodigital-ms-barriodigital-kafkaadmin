# ms-barriodigital-kafkaadmin

Microservicio administrador de Kafka de BarrioDigital (gemelo de `ms-barriodigital-rabbitadmin`):
tópicos, configuraciones y consumer groups del clúster de `ec2-kafka`.

Puerto `8087`. Acceso solo con JWT de Entra ID y rol **Admin**. Documentación en `/swagger-ui.html`.
